# Viora Media — установка и запуск

## Вариант 1: онлайн (как сейчас на Render)

1. Залей все файлы этой папки на хостинг (Render / GitHub Pages / Cloudflare Pages).
   Важно: index.html должен лежать в КОРНЕ сайта.
2. Открой сайт и сделай жёсткое обновление: Ctrl+Shift+R (иначе покажется старая версия из кеша).
3. Готово.

Если адрес сайта поменяется — добавь новый адрес (с https://, без слэша в конце)
в Google Cloud Console → Clients → viora → Authorised JavaScript origins.
Сейчас разрешены: https://viorasearch.onrender.com и http://localhost:8000

## Вариант 2: локально (на своём компьютере)

1. Открой терминал в этой папке.
2. Запусти:  python -m http.server 8000
3. Открой в браузере:  http://localhost:8000

Просто открыть index.html двойным кликом можно, но тогда НЕ работают:
PWA/офлайн-режим и кнопка «Подключить канал» (Google не разрешает OAuth с file://).

## Что уже настроено

- OAuth Client ID вшит в js/16_viora-v2-js.js (строка ~121) — кнопка «Подключить канал» работает.
- Scopes: youtube.readonly + yt-analytics.readonly — добавлены в Google Cloud.
- PWA: manifest + sw.js — на телефоне сайт можно «Установить» как приложение.

## Режим Testing в Google Cloud (важно!)

Приложение сейчас в режиме Testing: подключить канал могут ТОЛЬКО аккаунты
из списка Test users (Google Cloud → Audience → Test users, максимум 100 человек).
Сейчас там только vi6454918@gmail.com.

Чтобы канал мог подключить ЛЮБОЙ желающий:
Audience → Publish app → In production. Google попросит пройти верификацию
приложения (это бесплатно, но занимает время). Без подключения канала сайт
полностью работает для всех и так — по ссылке на любой канал.

## Проверка после запуска

1. Главная → YouTube → вставь ссылку на любой канал → аудит работает у всех.
2. Кнопка «Подключить канал» → выбери свой Google-аккаунт → появится
   предупреждение «Google hasn't verified this app» (норма для Testing) →
   Continue → разрешить. После этого в аудите появятся реальное удержание
   и сравнение Shorts/длинных по данным YouTube Analytics.

## Рекомендация по безопасности

Ключи Mistral и YouTube API лежат открыто в js/01_block_1.js (строки 4-5).
Любой может их увидеть и использовать. Рекомендуется перевыпустить ключи и:
- для YouTube API key поставить ограничение по HTTP referrer (адрес сайта);
- для Mistral — со временем спрятать за простой прокси-сервер.
