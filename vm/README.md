# Viora Media (V.media)

AI-аудит YouTube-каналов — клиентское веб-приложение (без бэкенда).

## Структура

```
index.html      — разметка + подключение стилей и модулей
css/styles.css  — все стили (объединены из исходных блоков)
js/             — 64 модуля, подключаются в порядке загрузки (defer)
```

JS-файлы пронумерованы в порядке выполнения (`01_...`, `02_...`).
Имена соответствуют версионным блокам исходного кода (`v3pack`, `v4pack`, `wiz`, ...),
чтобы было видно историю фич. Порядок и поведение полностью совпадают с исходным
однофайловым `index.html`.

## Запуск

Просто открой `index.html` в браузере. Внешние зависимости:
- Chart.js (CDN)
- YouTube Data API v3 и Mistral API (ключи задаются в JS)
